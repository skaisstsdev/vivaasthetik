# SEO VIVA Ästhetik: что сделано в коде и что нужно сделать вам

Дата: 17.11.2026. Всё, что можно сделать в коде, сделано. Ниже то, что можно сделать только из ваших аккаунтов.

---

## 0. Сначала: опубликовать сайт

Новая версия сайта лежит только на вашем компьютере. Google ничего не увидит, пока вы не опубликуете её на хостинге.
После публикации откройте `https://www.vivaasthetik.de/sitemap.xml`: там должно быть 44 адреса, и все начинаются с `https://www.`

### Переменные окружения на хостинге
Хостинг → Settings → Environment Variables. Добавьте (шаблон лежит в `site/.env.example`):

| Переменная | Значение | Когда |
|---|---|---|
| `NEXT_PUBLIC_SITE_URL` | `https://www.vivaasthetik.de` | сразу |
| `NEXT_PUBLIC_GSC_VERIFICATION` | код из шага 1 (Search Console) | после шага 1 |
| `NEXT_PUBLIC_GA_ID` | `G-XXXXXXXXXX` из шага 2 | только после юридического этапа, см. шаг 2 |
| `NEXT_PUBLIC_BING_VERIFICATION` | код Bing (по желанию) | шаг 4 |

После изменения переменных нужно заново опубликовать сайт (Redeploy).

## 1. Google Search Console (самое важное, ~15 минут)

Это бесплатный инструмент Google. Он показывает, проиндексирован ли сайт, по каким запросам вас находят и есть ли ошибки.

1. Откройте https://search.google.com/search-console и войдите тем же Google-аккаунтом, что управляет профилем компании.
2. Нажмите **«Добавить ресурс»** → выберите **«Префикс URL»** → введите `https://www.vivaasthetik.de/` → **Продолжить**.
3. Выберите способ подтверждения **«Тег HTML»**. Скопируйте значение `content="..."` из мета-тега (только длинный код внутри кавычек).
4. Вставьте этот код в переменную `NEXT_PUBLIC_GSC_VERIFICATION` на хостинге и опубликуйте сайт заново.
5. Вернитесь в Search Console и нажмите **«Подтвердить»**.
   - Вместо тега можно подтвердить домен через DNS: тип ресурса **«Домен»**, добавить TXT-запись у регистратора домена.
6. Слева **«Файлы Sitemap»** → в поле впишите `sitemap.xml` → **Отправить**. Статус должен стать «Успешно», найдено 44 страницы.
7. Слева **«Проверка URL»** → вставьте адрес и нажмите **«Запросить индексирование»** по очереди для главных страниц:
   - `https://www.vivaasthetik.de/de`
   - `/de/services`, `/de/prices`, `/de/about`, `/de/contact`
   - страницы `/de/services/botox`, `/de/services/faltenunterspritzung`, `/de/services/lippenkorrektur`, `/de/services/mesotherapie`
   - (в сутки доступно ограниченное число запросов, остальные Google найдёт сам по sitemap)
8. **Настройки → Пользователи и разрешения** → добавьте Наталью/меня по почте, если нужно.
9. Через 3–7 дней откройте **«Страницы»**: сколько проиндексировано и почему остальные нет. Через 2–3 недели **«Эффективность»** покажет запросы, клики и показы.

## 2. Google Analytics 4 (измерение звонков и записей)

**Сначала юридический этап.** До включения аналитики нужно обновить политику конфиденциальности (раздел про Google Analytics, согласие, срок хранения) и cookie-баннер. Код уже готов и отправляет данные только после того, как посетитель нажал «Принять», но включать его до правки текстов нельзя.

1. https://analytics.google.com → **Администратор** (шестерёнка) → **Создать → Аккаунт** → название «VIVA Ästhetik».
2. **Создать ресурс**: название «vivaasthetik.de», часовой пояс «Германия», валюта «Евро (EUR)».
3. Цель: «Получение потенциальных клиентов». Размер компании: «Небольшая».
4. Платформа **«Веб»** → URL `https://www.vivaasthetik.de`, название потока «Сайт». Нажмите «Создать поток».
5. Скопируйте **Идентификатор показателя** вида `G-XXXXXXXXXX`.
6. Вставьте в `NEXT_PUBLIC_GA_ID` на хостинге и опубликуйте заново (после юридического этапа).
7. В **Администратор → Сбор данных → Хранение данных** поставьте 14 месяцев.
8. Проверка: откройте сайт, нажмите «Принять» в баннере, позвоните по номеру (клик по ссылке) и отправьте тестовую форму. В GA4 откройте **Отчёты → В реальном времени**: должны появиться события.
9. **Администратор → События** → у событий включите переключатель **«Отметить как ключевое»**:
   - `booking_submitted`: запись через сайт
   - `contact_submitted`: форма «Kontakt»
   - `phone_click`: нажатие на номер телефона
   - `whatsapp_click`: переход в WhatsApp
10. **Администратор → Связи с продуктами → Связи с Search Console**: свяжите с вашим ресурсом из шага 1. Так в GA4 будут видны поисковые запросы.

Что считает код: `phone_click`, `whatsapp_click`, `email_click`, `booking_link_click`, `booking_submitted`, `contact_submitted`. В админке и без согласия не работает.

Профиль уже есть: 5,0 звёзд, 20 отзывов, 755 взаимодействий. Проверьте и доведите по пунктам.

Дополнение после «|» нарушает правила и может привести к блокировке профиля. Безопаснее: **«VIVA Ästhetik»** (или «VIVA Ästhetik Kassel», если так написано на вывеске и в Impressum).

3. **Сайт:** `https://www.vivaasthetik.de/de`. **Ссылка для записи:** `https://www.vivaasthetik.de/de/booking`.
4. **Часы.** Должны совпадать с сайтом: Пн–Пт 09:00–18:00, суббота по договорённости, воскресенье закрыто. Праздники отмечайте в «Особые часы».
5. **Услуги.** Раздел «Услуги»: добавьте все 12 с короткими описаниями (взять из сайта). Цены только после подтверждения.

8. **Публикации.** Раз в неделю: советы по уходу, новости практики. Без рекламы лекарств и без слова «акция».
9. **Атрибуты и вопросы:** «Говорят по-русски», «Онлайн-запись». Заполните «Вопросы и ответы» своими вопросами и ответами.

## 6. Что сделано в коде

- Адрес везде с www (`https://www.vivaasthetik.de`), canonical, hreflang (de, ru, x-default).
- Уникальный заголовок и описание у всех 46 страниц, на двух языках.
- Sitemap с 44 страницами и языковыми версиями, robots.txt (закрыта админка).
- Разметка schema.org: клиника (адрес, координаты, часы, телефон, каталог услуг), врач, сайт, «хлебные крошки», страницы услуг (MedicalWebPage), вопросы и ответы.
  - Звёзды отзывов в разметку **не** добавлены: Google не показывает звёзды для отзывов, которые компания размещает о себе.
- Картинка для превью в соцсетях (1200×630), favicon.ico, иконка для iPhone.
- Блок «Ваш врач» и «Weitere Behandlungen in Kassel» на страницах услуг (внутренние ссылки, подтверждение квалификации).
- «Ästhetische Medizin in Kassel» в хиро главной, «in Kassel» в блоке записи.
- Botox: основное название «Botulinumtoxin-Behandlung (Botox®)», слово Botox® только в скобках и в пояснительных текстах.
- Отзывы Google с кнопками «Читать полностью» и «Показать ещё», ссылка на профиль и на «оставить отзыв».
- Google Analytics 4 готов, включится только по ID и согласию (см. шаг 2). Подтверждение Search Console и Bing через переменные.
